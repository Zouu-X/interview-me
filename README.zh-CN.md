# User Context Interview · 让 Agent 更了解你

通过一场有针对性的访谈，帮助 Agent 了解你的目标、背景、偏好和协作边界，并整理成一份可以维护、迁移的个人协作档案。

[English](README.md)

重点是让每条信息回答一个问题：**知道这件事以后，Agent 下次应该怎么做？** 例如，把“做周计划时，太长的清单让我难以开始”整理为“先给三个优先行动，需要时再展开”，而不是为用户贴上性格标签。

## 怎么使用

**支持 Agent Skills 的产品：** 使用该产品提供的安装方式，导入整个 [`skills/user-context-interview`](skills/user-context-interview) 文件夹。保留根目录的 `SKILL.md` 和配套文件。安装位置、是否需要重启、如何调用，由所在产品决定；没有所有 Agent 通用的安装命令或斜杠命令。

装好后可以说：

> 使用 user-context-interview，通过一次简短访谈了解我，帮助我们以后更好地协作。

**不支持安装 Skill 的聊天产品：** 把 [`SKILL.md`](skills/user-context-interview/SKILL.md) 的正文复制到聊天里，再提出同样的请求。配套资料可读时会提供更多例子；不可读时，主文件也包含完整的基础流程。能否执行仍取决于该产品的能力与规则，不能承诺所有产品表现一致。

## 访谈会如何进行

1. 从你近期希望获得的帮助和已有背景开始，尽量不重复询问。
2. 默认每次一个主要问题，根据你的回答继续追问；可以跳过，也可以随时结束。
3. 把有用的信息转成具体协作偏好，区分长期偏好、当前情况和待确认问题。
4. 给出简明总结，按你已经授权的方式保存；没有保存授权时，先让你看到内容再决定。
5. 后续可以更新、纠错、迁移，或要求删除指定信息。

它不会因为你在做普通项目，就突然发起一场个人背景调查。

## 不同 Agent 怎么适配

| 所在产品的能力 | 使用方式 |
| --- | --- |
| 有交互式提问工具 | 适合选项的问题用工具，开放问题仍用文字。 |
| 没有提问工具 | 直接在聊天中提问，无需安装额外工具。 |
| 有长期记忆 | 在授权范围内使用产品已有的记忆功能。 |
| 能写文件，但没有记忆 | 保存为你指定或已经建立的私有 Markdown 档案。 |
| 只有聊天 | 输出可复制的档案，你可以带到下次聊天或另一个 Agent。 |

这个 Skill 本身不需要 API 密钥、外部服务或可执行脚本，也不会为所在产品凭空增加记忆能力。**可迁移的是协作方法和档案，不是各个平台的底层记忆系统。**

## 可以直接复制的请求

**第一次使用**

> 请花大约五分钟采访我，帮助你以后更好地协助我。每次问一个问题，重点了解我的当前目标和协作偏好。先给我总结，再决定是否保存。

**明确希望存入记忆**

> 请采访我，了解我的工作和协作偏好。如果你有长期记忆，请保存相关、非敏感的信息；没有的话，请给我一份可复用的协作档案。

**定期更新**

> 请查看你能访问的个人协作信息，针对可能已经变化的部分采访我，然后更新相关条目，保留其他内容。

**换一个 Agent**

> 请把我的协作档案导出为通用 Markdown，保留适用范围、来源、确认日期和待确认问题。让我看到导出的内容，不要上传到任何服务。

**纠正偏好**

> 更新我的偏好：普通进度汇报用一小段话就好；复杂决策仍然需要解释理由。

**要求忘记**

> 请从协作档案和你可以访问的记忆中删除我指定的信息，并说明实际更新了哪些位置。

## 个人档案与公开 Skill 分开

这个发布包只有空白模板，不含真实用户资料。实际访谈得到的个人档案应保存在用户指定或已建立的私有位置，不能默认写进可分享的 Skill 文件夹、公共仓库或团队知识库。

档案会保留用户说法的条件和适用范围，不把推测当成事实，也不收集密码等秘密。已有保存授权就直接执行；“采访我”本身不等于授权跨会话保存或对外传输资料。

新 Agent 需要收到档案，才有机会使用它。保存成功不等于永久记住；删除记忆条目也不等于删除聊天记录或已经导出的副本。

## 文件与验证

- `skills/user-context-interview/SKILL.md`：给 Agent 读取的英文主指令，运行时使用用户的语言。
- `skills/user-context-interview/references/interview-guide.md`：自适应追问、刷新和停止访谈的例子。
- `skills/user-context-interview/references/profile-format.md`：档案的来源、日期、合并和迁移规则。
- `skills/user-context-interview/assets/user-profile-template.md`：空白个人协作档案模板。
- `README.md`：英文说明和可在不同产品中执行的验收场景。

当前版本为 0.1.0。格式正确、文件链接有效，不代表已经验证所有 Agent 的表现，也不代表已经证明协作效果改善。真实效果需要在具体产品中运行访谈，并观察后续任务是否使用了这些偏好。
